Overview

Intelligent Tilt Monitoring with On-Device Edge Processing

The Wireless Tiltmeter is a 3-axis inclinometer engineered to detect and report ground and structural movements with low noise and fast latency. It runs continuous sampling in normal operation and switches to high-frequency capture when preset thresholds are exceeded.

Available in two variants: Tilt-XHP with external antenna for maximum range, and Tilt-IR with internal antenna ideal for railway track monitoring where exposed parts must be minimized.

Operational Modes

Three Smart Modes for Any Monitoring Scenario

Advanced operational modes that optimize workflows, extend battery life, and provide immediate alerts when movement matters most.

Periodic Mode

Configure reporting periods from 30 minutes to 24 hours. Ideal for continuous, scheduled monitoring of structures with predictable data requirements.

Triggered Measurements Mode

Motion detection sensor detects activity events from variations in absolute angle, angular velocity or acceleration. When significant movement is detected, it triggers high-frequency capture.

Event Detection Mode

Configurable thresholds trigger instant alert messages when readings exceed set limits. First-alert latency is typically less than 2 seconds for immediate awareness.

It tracks rapid or sudden inclination changes in structures, slopes, or rail systems — detecting motion that may signal instability, movement, or failure events in real time. The 3-axis MEMS sensor measures tilt relative to gravity with a range of ±90°.

The sensor continuously measures tilt angles and uses built-in algorithms to trigger alerts instantly when thresholds are exceeded. It supports Periodic mode, Triggered Measurements Mode (TMM), and Event Detection mode for flexible monitoring.

Tilt-XHP (LSG7ACL-BXLH-TIL) features an external antenna for maximum range, ideal for open-terrain deployments. Tilt-IR (LSG7ACL-BILR-TIL) has an internal antenna for railway track monitoring where exposed parts must be minimized.

Battery life depends on the selected reporting period. With a 1-hour reporting interval, the Tilt-XHP achieves up to 5.3 years. With a 6-hour interval, it reaches up to 7.7 years. The device uses a user-replaceable 3.6V D-size LSH20 battery.

Configuration can be done locally via the Worldsensing App using Bluetooth connectivity, or remotely using CMT Edge for single-network deployments and CMT Cloud for multi-project oversight. USB-C connector also available.

Ideal for railway tracks, slopes, retaining walls, tunnels, bridges, mining pits, and tailings dams — anywhere fast, autonomous tilt event detection enhances safety and operational awareness.
